## Um projeto meu

Criei o **Repo Pulse** para acompanhar como um repositório muda ao longo do tempo. Cada coleta guarda as métricas do GitHub e o commit que estava na branch padrão naquele momento. No histórico, dá para escolher uma leitura e abrir o código daquela versão.
